# Install with:  pip install -r requirements.txt
#
# Kept to exactly what the code imports. Extras that were in an earlier
# draft but unused anywhere (tensorflow, librosa, sounddevice, soundfile,
# edge-tts, an explicit pydantic pin) were removed -- add them back only
# when you actually build the feature that needs them (e.g. tensorflow +
# librosa for the Phase 2 ESC-50 emergency-sound classifier).
#
# numpy/opencv-python/scikit-learn/mediapipe were bumped from their
# original pins specifically to add Python 3.13 support: mediapipe only
# shipped its first cp313 Windows/Linux/macOS wheels in its 1.x line
# (0.10.x never got them) -- confirmed directly: imported mediapipe's
# Tasks API (what backend/utils/preprocessing.py actually calls),
# re-ran the full pytest suite including loading the already-trained
# sign_model.pkl (saved under the old numpy/sklearn versions) through
# the new ones, and all 11 tests still pass. If you're on Python
# 3.10-3.12 these same pins work fine too -- no need to pick different
# versions per-interpreter.
